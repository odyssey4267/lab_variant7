## Задание

Дана вещественная матрица размерности n × m. Нужно получить логический вектор,
k-й элемент которого равен `True`, если выполнено условие, и `False` иначе:

| Уровень | Условие | Длина вектора |
|---|---|---|
| 1 | все элементы k-го столбца нулевые | m |
| 2 | элементы k-й строки упорядочены по убыванию | n |
| 3 | k-я строка симметрична | n |

## Требования

Python 3.9+, сторонние библиотеки не нужны.

## Запуск

```bash
python main.py                       # ввод с клавиатуры
python main.py examples/input1.txt   # ввод из файла
```

Формат файла: первая строка `n m`, затем `n` строк по `m` чисел через пробел
(десятичная запятая допускается).

## Пример

Вход (`examples/input2.txt`):

```
4 5
9 7 5 3 1
1 2 3 2 1
0 0 0 0 0
4 4 6 4 4
```

Выход:

```
1) Все элементы k-го столбца нулевые (k = 1..m):
    [False, False, False, False, False]
2) Элементы k-й строки упорядочены по убыванию (k = 1..n):
    [True, False, True, False]
3) k-я строка симметрична (k = 1..n):
    [False, True, True, True]
```

## Принятые соглашения

- Убывание нестрогое: `a[j] >= a[j+1]`.
- Строка из одного элемента считается и упорядоченной, и симметричной.
- Вещественные числа сравниваются с допуском 1e-9.
