# Тестирование работы с хранилищем (ЛР №5)

Инструмент — pytest; база данных создаётся заново для каждого теста (SQLite в памяти), API
проверяется через `fastapi.testclient.TestClient`. Каталог тестов — `tests/storage/`.

Запуск: `pytest tests/storage -v --cov=src/matrix_lab --cov-report=term-missing`

## Тестовые сценарии

| № | Сценарий | Ожидаемый результат | Файл тестов |
|---|---|---|---|
| ST-01 | Записать матрицу и прочитать её обратно | данные, размеры и теги совпадают | test_repository.py |
| ST-02 | Добавить матрицу с занятым именем | `DuplicateError` / HTTP 409 | test_repository.py, test_api.py |
| ST-03 | Некорректные данные: пустая матрица, неровные строки, nan, inf, пустое или длинное имя | `InvalidDataError` / HTTP 422 | test_repository.py, test_api.py |
| ST-04 | Изменить имя, данные (та же и другая форма), теги, примечание | значения заменены, лишние ячейки удалены | test_repository.py, test_api.py |
| ST-05 | Удалить матрицу | удалены ячейки, анализы, результаты (каскад); повторное удаление — 404 | test_repository.py, test_api.py |
| ST-06 | Запись с несуществующим внешним ключом | `IntegrityError` (внешние ключи включены) | test_repository.py |
| ST-07 | Список: фильтр по тегу и части имени, сортировка, страницы | верные записи и общее число | test_repository.py, test_api.py |
| ST-08 | Недопустимые параметры списка (поле сортировки, limit, offset) | `InvalidDataError` / HTTP 422 | test_repository.py, test_api.py |
| ST-09 | Поиск по имени со спецсимволами `%`, `_`, `\` | символы ищутся буквально | test_repository.py |
| ST-10 | Запуск обработки матрицы | три вектора совпадают с логикой ЛР №1–3 | test_repository.py, test_api.py |
| ST-11 | Обработка с разным `eps` и `eps` из настроек | результат зависит от `eps` | test_repository.py, test_api.py |
| ST-12 | Настройки: чтение, запись, недопустимые значения | значения по умолчанию, 422 на ошибки | test_repository.py, test_api.py |
| ST-13 | Настройки влияют на список (размер страницы, сортировка) | список использует сохранённые значения | test_api.py |
| ST-14 | Ограничение размера матрицы | отказ при превышении `MAX_CELLS` | test_repository.py |
| ST-15 | SQL-скрипты: создание схемы, тестовые данные, ограничения, каскад | `IntegrityError` на нарушениях | test_sql_scripts.py |
| ST-16 | Swagger UI, схема OpenAPI и главная страница доступны | HTTP 200 | test_api.py |
| ST-17 | Статистика, прогноз и сводка (уровень 3) | значения совпадают с ручным расчётом | test_analytics.py, test_api_analytics.py |
| ST-18 | Миграции: применить, откатить, повторить, работа на мигрированной базе | таблицы создаются и удаляются, поле `note` появляется и исчезает | test_migrations.py |
| ST-19 | Скрипты `db_init`, `db_demo`, `serve_api`, `export_openapi` | запускаются без ошибок | test_scripts.py |
