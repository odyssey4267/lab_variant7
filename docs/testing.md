# План тестирования

## Цели

Подтвердить, что программа правильно строит три логических вектора и корректно реагирует на
неверные входные данные.

## Уровни и виды тестов

| Уровень | Что проверяется | Где |
|---------|-----------------|-----|
| Модульные тесты логики | три условия варианта 7, проверка матрицы | `tests/test_logic.py` |
| Модульные тесты ввода | разбор формата `n m` + строки, ошибки формата, NaN/inf | `tests/test_io.py` |
| Тесты точки входа | запуск на примере из файла, отсутствующий файл, обрыв ввода | `tests/test_main.py` |
| Статический анализ | стиль и простые ошибки | `flake8 src tests` |

## Тестовые данные

Граничные и характерные случаи: матрица 1 × 1; одна строка; один столбец; нулевая матрица;
равные соседние элементы; отрицательные числа; нулевые значения `-0.0` и `1e-12`;
чётная и нечётная длина строки; десятичная запятая; пустая и непрямоугольная матрица;
нечисловые значения, `nan`, `inf`, переполнение `1e999`; обрыв ввода (EOF).

## Критерии успешности

- все тесты проходят: `python -m unittest discover -s tests -t .`;
- `flake8 src tests` не выдаёт замечаний;
- автоматическая проверка (CI) на GitHub Actions проходит для Python 3.9 и 3.12.

## Запуск

```bash
python -m unittest discover -s tests -t . -v
flake8 src tests
```

## Ответственность и порядок

Тесты пишутся вместе с кодом каждой функции; перед слиянием в `develop` запускается полный набор.
Результаты автоматического запуска видны во вкладке Actions репозитория.
