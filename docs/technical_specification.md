## Техническое задание на разработку программы «Логические векторы по вещественной матрице»

*(структура по ГОСТ 19.201-78 «Техническое задание. Требования к содержанию и оформлению»)*

### 1. Введение

**Наименование программы:** «MatrixLogicVectors» (логические векторы по вещественной матрице).

**Краткая характеристика области применения.** Программа предназначена для учебных целей: отработка навыков работы с двумерными массивами (матрицами), логическими условиями и построения логических векторов-признаков по строкам и столбцам матрицы. Может использоваться как фрагмент более крупных программ обработки табличных числовых данных.

### 2. Основание для разработки

2.1. Основанием для разработки является задание на лабораторную работу №1 «Разработка структуры проекта» по дисциплине "инструментальные средства разработки программного обеспечения", вариант 7.

2.2. Наименование темы разработки: «Построение логических векторов по вещественной матрице размерности n × m».

2.3. Исполнитель: Калинина П.Н. Т9-ИП-25-1. Руководитель: Кургасов В.В..

### 3. Назначение разработки

3.1. **Функциональное назначение.** По заданной вещественной матрице A размерности n × m программа формирует логические векторы, k-й элемент которых принимает значение `True`, если выполнено указанное условие, и `False` в противном случае. Условия:

| № | Условие для k-го элемента вектора | Длина вектора |
|---|-----------------------------------|---------------|
| 1 | все элементы k-го столбца матрицы нулевые | m |
| 2 | элементы k-й строки матрицы упорядочены по убыванию | n |
| 3 | k-я строка матрицы симметрична | n |

3.2. **Эксплуатационное назначение.** Программа используется студентами и преподавателем для демонстрации и проверки обработки матриц; работает в консольном режиме.

### 4. Требования к программе

#### 4.1. Требования к функциональным характеристикам

4.1.1. *Состав выполняемых функций:*

- ввод размерности матрицы n и m (целые, n ≥ 1, m ≥ 1);
- ввод элементов матрицы построчно (вещественные числа) с клавиатуры либо чтение из текстового файла;
- проверка корректности входных данных;
- построение вектора по условию 1: `V1[k] = True`, если ∀i: a[i][k] = 0 (k = 1..m);
- построение вектора по условию 2: `V2[k] = True`, если ∀j: a[k][j] ≥ a[k][j+1] (k = 1..n); строка из одного элемента считается упорядоченной;
- построение вектора по условию 3: `V3[k] = True`, если ∀j: a[k][j] = a[k][m−1−j] (k = 1..n); строка из одного элемента симметрична;
- вывод исходной матрицы и трёх полученных векторов на экран.

4.1.2. *Организация входных данных.* Формат ввода (файл или консоль): первая строка — два целых числа `n m`; далее n строк по m вещественных чисел, разделённых пробелами. В качестве десятичного разделителя допускаются точка и запятая.

4.1.3. *Организация выходных данных.* Для каждого условия выводится логический вектор вида `[True, False, ...]` с пояснением, к какому условию он относится. Нумерация k на выводе — с 1.

4.1.4. *Особенности вычислений.* Вещественные числа сравниваются с допуском ε = 10⁻⁹ (элемент считается нулевым, если |x| ≤ ε; элементы считаются равными, если |x − y| ≤ ε), чтобы исключить влияние ошибок округления.

4.1.5. *Обработка ошибок.* При некорректном вводе (нечисловые данные, неверное число строк или элементов, n < 1, m < 1, отсутствие файла) программа выдаёт понятное сообщение об ошибке; при чтении из файла завершается с ненулевым кодом возврата, при вводе с клавиатуры — повторно запрашивает данные.

#### 4.2. Требования к надёжности

4.2.1. Программа не должна аварийно завершаться при любых входных данных; все ошибки ввода обрабатываются.

4.2.2. Корректность результата подтверждается автоматическими модульными тестами (покрытие всех трёх условий, граничных случаев: n = 1, m = 1, нулевая матрица, равные элементы, отрицательные числа).
